v2.19 測試報告

一、程式與檔案檢查
- game.js、game-en.js、home.js、home-en.js、cards.js、cards-en.js、catalog.js、catalog-en.js 均通過 node --check。
- index.html、index-en.html、battle.html、battle-en.html 未發現重複 ID。
- 四個 HTML 的站內檔案參照均存在。
- 英文遊戲程式的執行字串未檢出中文介面文字；語言切換按鈕保留「繁體中文」屬刻意設計。

二、英文換牌檢查
- 英文版換牌標題、說明、確認按鈕與上限提示均為英文。
- 英文版被選取的換牌卡片遮罩顯示 SWAP，不再顯示中文「換」。
- 中文版仍顯示「換」。

三、執行階段尺寸偵測
- 使用 window.visualViewport 取得瀏覽器實際可視寬高。
- 同時讀取 window.screen 寬高與螢幕比例，並偵測直向／橫向及粗略指標裝置。
- 視窗改變、手機轉向、行動瀏覽器網址列伸縮時會重新計算。
- 自動配置：desktop-standard、desktop-wide、desktop-tall、mobile-portrait、mobile-landscape。

四、實際瀏覽器尺寸測試
- 1366×768：頁面 scrollWidth 等於 clientWidth；scrollHeight 等於 clientHeight；棋盤與手牌皆位於可視範圍內。
- 1280×720：無水平或垂直頁面溢位；棋盤與手牌皆位於可視範圍內。
- 390×844 手機直向：遊戲畫面 390×768，棋盤、雙方資訊、操作按鈕及手牌均位於單一可視畫面內。
- 360×640 手機直向：無頁面溢位；短螢幕模式自動縮小棋盤牌與手牌。
- 320×568 小型手機直向：無頁面溢位；保留棋盤、領主能力、PASS 與手牌操作。
- 844×390 手機橫向：自動切換三欄對戰配置；無頁面溢位。
- 667×375 手機橫向：棋盤與手牌位於同一可視畫面內。
- 中文與英文對戰頁測試均未出現未捕捉的 JavaScript 錯誤。

五、首頁動畫測試
- 390×844、320×568、667×375：中文與英文首頁動畫面板均限制於實際可視範圍內。
- 英文文字較長時由動畫內容區內部捲動，不會把操作按鈕推離螢幕。
