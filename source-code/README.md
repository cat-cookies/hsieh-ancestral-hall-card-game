# 謝氏宗祠・宗族牌局

這是一款可直接發布至 GitHub Pages 的單人文化資產教育卡牌遊戲。

遊戲以三輪兩勝、起手換牌、輪流出牌、PASS 與跨輪手牌管理為核心，將屏東內埔謝氏宗祠的空間格局、建築裝飾、文字禮制、祭祀制度與宗族記憶轉化為可互相連動的卡牌。

遊戲目的不只是取得高分，而是讓玩家在出牌過程中逐步理解：謝氏宗祠的文化價值並非集中在單一構件，而是由宗族發展、客家聚落、祭祀制度、空間秩序、文字教化與木構工藝共同構成。

## 最終版特色

- 30 張文化卡牌，每張均有彩色遊戲插圖。
- 背景使用謝氏宗祠實景照片。
- 卡牌提供「遊戲效果」、「說明」與「文化資產價值」。
- 組合技不在場上預先提示，只有成功觸發時才顯示動畫。
- 11 組分層文化組合技，包含基礎連結、中階主題連結與高階整體連結。
- 三種電腦難度：簡單、普通、困難。
- 困難模式具備手牌保存、補強組合、兩步預判、低成本過線與較精準 PASS 判斷。
- 完整新手教學，可隨時略過或重新開啟。
- 提供回主頁、重新開始、規則、教學與資料來源等功能。
- 適用桌面與手機瀏覽器。
- 無需安裝套件或伺服器。

## 最簡單的發布方式

詳細步驟請看 [`UPLOAD_GUIDE.md`](UPLOAD_GUIDE.md)。

## 遊戲規則摘要

1. 雙方起手各抽 10 張牌，第一輪可換至多 3 張。
2. 第二輪補 2 張、第三輪補 1 張，並各可再換 1 張。
3. 每次行動只能選擇一項：出一張牌、使用一次領主能力、或 PASS。
4. 一旦 PASS，本輪不能再出牌。
5. 雙方都 PASS 後比較總分，較高者取得一個勝場。
6. 最多進行三輪，先取得兩個勝場者獲勝。
7. 卡牌分為空間牌、裝飾牌與文字牌。
8. 卡牌會因文化關聯而連動加分；大型組合技的條件可在規則頁查看，但遊戲中不會提示尚缺哪些牌。

## 文化資產教學設計

卡牌內容依謝氏宗祠專題研究與文化資產資料整理，並以一般觀眾容易理解的方式呈現：

- 空間價值：門樓、禾埕、前堂、天井、後堂、橫屋與化胎。
- 工藝價值：斗栱彩繪、燕尾脊、五行石、壽字磚與圖樣裝飾。
- 禮制價值：祖牌、神位、天公爐、春祭秋嘗與昭穆秩序。
- 文字價值：寶樹堂、木本水源、門聯、棟對與宗祠題字。
- 社會價值：始祖嘗會、宗族管理、聚落記憶與世代生活。
