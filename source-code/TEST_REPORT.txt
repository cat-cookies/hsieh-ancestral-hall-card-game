檢查日期：2026-08-02

一、本次調整
1. 全站固定使用單一網頁字型「LXGW WenKai TC（霞鶩文楷 TC）」。
2. CSS 字型宣告不含任何備援字型堆疊。
3. 首頁、按鈕、選單、規則、教學、卡牌名稱、卡牌效果、卡牌說明與卡牌插圖文字皆採同一字型。
4. 卡牌插圖由 data URI 圖片改為內嵌 SVG，使 SVG 文字可繼承頁面同一字型。
5. 獨立卡背圖移除中文字，避免外部 SVG 圖片因隔離環境產生不同字型。

二、字型範圍
LXGW WenKai TC 為繁體中文版本，包含 BIG5 漢字、臺灣常用字與 IICore 範圍；足以涵蓋本遊戲全部繁體中文內容。

三、發布注意事項
字型由 Google Fonts 線上載入。網站需連線才能載入統一字型；CSS 未設定第二套備援字型。
