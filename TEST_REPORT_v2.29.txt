謝氏宗祠・宗族牌局 v2.29 測試報告

一、靜態結構檢查
1. index.html、index-zhuyin.html、index-en.html、battle.html、battle-zhuyin.html、battle-en.html 均可解析。
2. 六頁均無重複 HTML ID。
3. 六頁引用之本機 CSS、JavaScript 與圖片資源均存在。
4. js 目錄內 15 個 JavaScript 檔案均通過 node --check。

二、遊戲資料完整性
1. 正體中文與英文資料各有 30 張卡牌，卡牌 ID 均唯一。
2. 正體中文與英文資料各有 12 組大型組合技，引用之卡牌 ID 均有效。
3. 文化標記政策已寫入中英文資料，且 game.js、game-en.js 均無稀有度權重常數或稀有度選牌加權。
4. 前堂、後堂、祭祀廳下、始祖嘗會及中軸／頂層組合之調整，在中英文資料與計分程式中一致。

三、瀏覽器流程檢查
測試環境：Headless Chromium，1280×800、1440×900、390×844。
1. 六個入口頁面均無 console error 或 page error。
2. 三種語言對戰頁之「略過導覽」與「下一幕」在桌機視窗內可見。
3. 三種語言對戰頁均可略過導覽、產生 10 張起手牌、完成換牌並進入正式對局。
4. 390×844 手機直向下，首頁、導覽、換牌及正式對局均無水平溢位。
5. 手機對戰頁可直接操作回到首頁、遊戲指南、卡牌總覽、結束遊戲與字級調整。

四、回饋流程檢查
1. 遊戲結束頁可開啟精簡回饋表單。
2. 未填寫理解程度或文字回饋時會阻止空白送出。
3. 完成填答後顯示「回饋已儲存在此裝置」，並啟用 CSV 下載按鈕。
4. 未設定 feedbackFormUrl 時，外部 Google 表單按鈕保持隱藏。
5. 瀏覽器禁止 localStorage 時，仍可保留目前工作階段資料供 CSV 匯出。

五、初步卡牌平衡檢查
方法：固定亂數種子，隨機抽取 20,000 組、每組 5 至 10 張不重複卡牌，估算各卡牌加入牌面前後之總分邊際貢獻。此方法用於偵測分數尖峰，不等同完整對局模擬。
結果：卡牌邊際貢獻最大與最小差距由約 11.66 降至 10.23。前堂約由 13.79 降至 12.77；後堂約由 16.71 降至 15.27；始祖嘗會約由 11.24 降至 10.28。核心卡仍保有策略地位，但單一路線支配程度降低。
限制：尚須透過不同背景、年齡及高齡玩家之實際對局，持續檢查勝率、卡牌使用率、誤解率與操作時間。

結論：v2.29 已通過本次靜態、流程、跨語言、手機版、回饋與初步平衡檢查，可作為下一輪一般民眾及高齡玩家測試版本。
