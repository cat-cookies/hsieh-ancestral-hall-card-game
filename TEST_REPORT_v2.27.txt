謝氏宗祠・宗族牌局 v2.27 自我檢驗報告
產出日期：2026-08-02

一、修正目標
1. 不再用持續縮小卡牌文字的方式，勉強把十張手牌塞進單一畫面。
2. 依 visualViewport、瀏覽器縮放後的實際可視區、直向／橫向、觸控裝置、語言、注音模式及使用者字級共同校正。
3. 卡牌維持可讀字級下限；卡牌數量超過可用寬度時，改用水平捲動。
4. 視窗變更、手機旋轉、網址列伸縮、字級變更與網頁字型載入後，均重新校正。
5. 避免上方工具列、中央棋盤及下方手牌互相推擠而超出視窗。

二、程式檢查
- js/accessibility.js：通過 node --check。
- js/layout-calibration.js：通過 node --check。
- js/game.js、js/game-en.js：通過 node --check。
- cards、catalog、home、heritage-journey、zhuyin 等全部 JavaScript：通過 node --check。
- 正體、注音及英文六個 HTML 入口均使用 v2.27 快取版本。
- 搜尋使用者可見資料，未發現「五穀豐收圖樣」或「不加圖樣」等錯誤命名。
- 正體與英文對戰程式均保留結束遊戲、取消結束及確認結束事件處理。

四、設計決策
- 「一個畫面容納所有內容」不再等同於「把所有字縮小」。
- 棋盤與手牌先分配固定責任區；手牌列以水平捲動處理數量，文字保留最低可讀尺寸。
- 中文、英文、注音使用不同的卡牌寬高、行數及字級下限。
- 使用者字級仍會影響內容，但成長幅度受版面上限控制，避免再次把棋盤推出視窗。
- 選牌效果說明使用浮動層，不增加頁面流程高度。

五、已知測試限制
- 注音版手機未完成完整自動化全流程測試；其手機配置與正體版共用同一校正引擎，並另加注音高度與字級規則。注音桌面及正體手機已分別完成實際瀏覽器檢查。
