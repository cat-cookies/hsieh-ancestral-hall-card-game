# 謝氏宗祠・宗族牌局 v2.31

以屏東謝氏宗祠的歷史、空間格局、建築裝飾、祭祀文字、宗族制度、地方記憶、研究方法與保存倫理為內容基礎，結合最多三輪對戰、平衡起手、文化組合技、效果牌與七條循序學習支線的教育型卡牌遊戲。

## 目前正式資料

- 卡牌：46 張（40 張文化牌＋6 張效果牌）
  - 空間牌 11 張
  - 裝飾牌 16 張
  - 文字牌 13 張
  - 效果牌 6 張
- 文化組合技：36 組
  - 二張簡易組合 24 組
  - 三至四張進階組合 12 組
- 領主：2 位
- 電腦難度：3 段
- 文化學習支線：7 條，共 43 題
- 拼圖：7 塊

首頁數字由 `js/cards.js` 或 `js/cards-en.js` 的實際資料動態計算，後續擴充時不再分別手動維護卡牌與組合技總數。

## 對戰規則

1. 每場最多進行三輪。
2. 雙方各使用相同的 46 張牌庫，起手抽 12 張。
3. 起手固定配置為空間牌 4 張、裝飾牌 4 張、文字牌 3 張及效果牌 1 張，並至少具有兩組二張簡易組合的可能性。
4. 第一輪可換至多 4 張；第二、三輪各補 2 張並可換 1 張。
5. 每次行動可擇一：打出一張牌、使用一次性領主能力或 PASS。
6. 分數較高者取得該輪一個勝場；平局時雙方皆不取得勝場。
7. 任一方先取得兩個勝場即獲勝；完成第三輪後仍未達兩勝時，比較累積勝場，勝場相同即為和局。

## 平衡設計

- 難度只改變電腦的換牌、選牌、領主能力與 PASS 決策，不改變牌力、抽牌數或組合技分數。
- 文化標記「常見、珍稀、史詩、傳說」只表示文化特殊性或代表性，不影響卡牌力量或電腦選牌。
- 謝安領主能力最高可增加 6 點；謝玄僅能在落後時使用，增加 7 點。
- 效果牌只調整己方手牌、墓地或列區，不直接摧毀、封鎖或大量扣除對手資源。
- 24 組二張簡易組合高於 12 組進階組合，使初次玩家較容易獲得成功回饋。

## 文化內容界線

文化卡牌、支線題目與解說以專題、修復計畫、官方文化資產資料、現地調查及訪談整理為基礎。卡牌力量、技能、組合名稱與加分屬遊戲化轉譯，不代表文化資產價值分級、正式建築術語或已證實的歷史因果。訪談說法、地方稱呼及待考證內容，應在說明中保留其來源與不確定性。

## 驗證文件

- `FINAL_AUDIT_v2.31.md`：整體一致性、內容、規則及風險檢查。
- `BALANCE_REPORT_v2.31.md`：卡牌邊際貢獻、組合分布、領主與起手平衡。
- `TEST_REPORT_v2.31.txt`：自動化資料、語法、版面、瀏覽器與完整對局測試結果。
- `TESTING_TEMPLATE_v2.31.csv`：供一般民眾、高齡者與不同卡牌經驗者進行實際可接受性測試。
- `tools/full-match-smoke-v2.31.py`：以簡化固定策略執行 2 位領主 × 3 段難度的端對端流程檢查；結果不得視為真人勝率。
- `docs/archive/`：歷史版本紀錄；其中數字不得視為目前版本資料。

## GitHub Pages 上傳

1. 解壓縮 ZIP。
2. 將全部檔案與資料夾上傳至 GitHub 儲存庫根目錄。
3. 覆蓋既有檔案並提交。
4. 等待 GitHub Pages 部署後，以 `Ctrl + F5` 強制重新整理。

不可只上傳 `index.html`，否則其他語言、文化支線、圖片與程式資源不會同步更新。
