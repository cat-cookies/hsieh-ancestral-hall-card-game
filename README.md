# 謝氏宗祠・宗族牌局

一款可直接部署至 GitHub Pages 的單人網頁卡牌遊戲。遊戲以三輪兩勝、起手換牌、輪流出牌、Pass 與三列配置等卡牌資源管理概念為基礎，將屏東內埔謝氏宗祠的歷史人物、建築空間、裝飾工藝與文字禮制轉化為可連動的文化卡牌。

> 本專案為文化資產教育與設計實作原型，並非《昆特牌》官方作品。未使用《巫師》或《昆特牌》的官方商標、圖像、卡牌資料或程式碼。

![遊戲首頁預覽](screenshots/start-screen.png)

## 遊戲內容

- 單人對戰電腦對手。
- 三輪兩勝；平輪時雙方各得一個勝場標記。
- 起手十張牌，可換至多三張；第二輪補兩張、第三輪補一張，並各可再換一張。
- 每次行動可出一張牌、使用一次領主能力，或 Pass。
- 三類出牌區：空間牌、裝飾牌、文字牌。
- 兩位領主：謝安、謝玄。
- 三十張文化卡牌與多組文化連結，例如「二堂二橫」、「中軸成序」、「五行護脈」。
- 卡牌文化說明、出牌紀錄、累計勝敗與響應式畫面。

## 本機開啟

最簡單的方式是直接開啟 `index.html`。若瀏覽器限制本機檔案載入，可在資料夾內執行：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的儲存庫，例如 `hsieh-ancestral-hall-card-game`。
2. 將本資料夾中的所有檔案上傳到儲存庫根目錄。
3. 開啟儲存庫的 `Settings` → `Pages`。
4. 在 `Build and deployment` 的 `Source` 選擇 `GitHub Actions`。
5. 推送到 `main` 後，`.github/workflows/pages.yml` 會自動部署。
6. 專案網站通常會是：

```text
https://你的GitHub帳號.github.io/hsieh-ancestral-hall-card-game/
```

也可在 Windows PowerShell 使用專案內的 `deploy-to-github.ps1`，但須先於 GitHub 建立空白儲存庫。

## GitHub Project 建議設定

GitHub 的「Project」是工作管理看板；實際存放遊戲與發布 Pages 的是「Repository」。建議設定如下：

- Project 名稱：`昆特牌的規則和遊戲系統`
- 預設儲存庫：指向遊戲儲存庫
- 簡短描述：`以昆特牌式三輪資源管理機制轉譯屏東謝氏宗祠文化內容的線上卡牌遊戲。`
- 能見度：可依團隊協作需求維持私有；這不等同於 Pages 網站或儲存庫的能見度

完整可複製文字見 [`GITHUB_PROJECT_SETTINGS.md`](GITHUB_PROJECT_SETTINGS.md)。

## 資料與設計界線

文化內容主要參考：

- 文化部文化資產局，內埔鄉謝氏宗祠。
- 國家文化記憶庫，內埔鄉謝氏宗祠修復及再利用計畫。
- 《文化資產推廣與數位科技應用之研究－以屏東謝氏宗祠為例》（國立雲林科技大學文化資產維護系，2026）。
- 《昆特牌的規則和遊戲系統》（阿高整理，2017 v3），僅作為三輪、手牌、換牌、三列與 Pass 機制的規則參考。

卡牌力量值、加成、連結名稱、領主能力與電腦對手邏輯均為本原型的遊戲化轉譯，不代表史學、建築史或宗族研究上的因果判斷。詳見 [`SOURCES.md`](SOURCES.md)。

## 技術

純 HTML、CSS 與 JavaScript，無框架、無套件依賴、無伺服器端資料庫。遊戲紀錄僅儲存在瀏覽器 `localStorage`。
