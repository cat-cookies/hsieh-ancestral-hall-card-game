# 謝氏宗祠・宗族牌局 v2.17

以謝氏宗祠的空間格局、建築裝飾、祭祀文字、宗族制度與地方記憶為內容基礎，結合三輪對戰、手牌管理及文化組合技的文化資產教育卡牌遊戲。

## 本版重點

- 網站開啟後先播放可略過的背景故事動畫，完成後才顯示首頁及對局設定。
- 故事改採短句、具體感官與留白較多的敘事方式，不再以「本幕重點」直接解釋寓意。
- 手牌改為點一下提起／放回，450 毫秒內快速點第二下才會正式出牌。
- 音訊控制提高至 200%，並將新版預設值提高為：總音量 140%、環境音 125%、遊戲效果 150%、敘事提示 135%。
- 新增明確的音訊啟用按鈕，以處理瀏覽器限制自動播放聲音的情況。
- 提供完整繁體中文及英文版本；兩種語言使用分開的 HTML、卡牌資料及程式資源，不會把兩套文字同時載入同一頁。

## 中文與英文入口

```text
index.html       中文首頁
battle.html      中文對戰頁
index-en.html    English home page
battle-en.html   English battle page
```

英文版使用獨立資源：

```text
js/cards-en.js
js/catalog-en.js
js/home-en.js
js/game-en.js
```

中文版使用：

```text
js/cards.js
js/catalog.js
js/home.js
js/game.js
```

## GitHub Pages 上傳

1. 解壓縮 ZIP。
2. 將解壓縮後資料夾內的全部檔案與資料夾上傳至 GitHub 儲存庫根目錄。
3. 覆蓋既有檔案並提交變更。
4. 等待 GitHub Pages 重新部署，再按 `Ctrl + F5` 強制重新整理。

不可只上傳 `index.html`，否則英文頁面、對戰頁、卡牌資料、圖片與程式資源無法完整載入。
