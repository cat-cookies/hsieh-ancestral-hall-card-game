# 謝氏宗祠・宗族牌局

這是一款以三輪對戰、手牌管理與文化組合技為核心的文化資產教育卡牌遊戲。內容以屏東謝氏宗祠的空間格局、建築裝飾、祭祀文字、宗族制度與地方生活記憶為基礎。

## 網站結構

本版採真正雙頁設計：

- `index.html`：首頁與對局設定。
- `battle.html`：實際戰鬥頁面。

玩家在首頁選擇領主與難度後，按下「開始牌局」會前往新的對戰頁，並直接進入起手換牌流程。

## 必要檔案

GitHub 儲存庫根目錄必須同時保留：

```text
index.html
battle.html
styles.css
assets/
js/
.nojekyll
```

不可只上傳 `index.html`，否則「開始牌局」會找不到對戰頁或缺少程式與圖片。

## 技術特性

- 純 HTML、CSS、JavaScript，無需安裝或建置。
- 適用 GitHub Pages。
- 首頁與對戰頁分離。
- 三種電腦難度。
- 文化組合技與動畫。
- 卡牌完整說明與文化資產價值說明。
- 使用單一繁體中文書法字型設定。
