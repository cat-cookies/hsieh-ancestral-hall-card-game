# 謝氏宗祠・宗族牌局 v2.30

以屏東謝氏宗祠的歷史脈絡、空間格局、風水觀念、建築裝飾、文字禮制、宗族制度、地方記憶與文化資產研究方法為內容基礎，結合三輪對戰、平衡起手、簡易／進階文化組合、效果牌及七條循序學習支線的教育型卡牌遊戲。

## 三種獨立語言入口

```text
index.html             正體中文首頁，不顯示注音
battle.html            正體中文對戰頁，不顯示注音
index-zhuyin.html      正體中文＋注音符號首頁
battle-zhuyin.html     正體中文＋注音符號對戰頁
index-en.html          English home page
battle-en.html         English battle page
```

英文版使用獨立的英文資料與程式：

```text
js/cards-en.js
js/catalog-en.js
js/home-en.js
js/game-en.js
js/heritage-journey-en.js
```

正體中文版使用：

```text
js/cards.js
js/catalog.js
js/home.js
js/game.js
js/heritage-journey.js
```

注音版在正體中文內容上另載入 `js/zhuyin.js`，以 Ruby 標記顯示注音。

## v2.30 學習深度與遊戲平衡擴充

### 卡牌與組合

- 卡牌由 30 張擴充為 46 張：空間牌 11 張、裝飾牌 16 張、文字牌 13 張、效果牌 6 張。
- 新卡均取自專題已整理的建築、宗族、地方記憶、研究方法與數位轉譯內容，不以湊數方式增加。
- 組合技共 30 組：18 組二張「簡易組合」、12 組三至四張「進階組合」。
- 簡易組合數量較多，讓首次遊玩者較容易形成有效策略；進階組合保留長期熟悉與精熟空間。
- 文化標記只表示文化特殊性、代表性或收藏價值，不增加力量，也不進入電腦選牌權重。

### 起手、補牌與效果牌

- 雙方以 46 張牌庫各抽 12 張平衡起手牌。
- 起手牌至少包含 1 張效果牌，並保證至少存在 2 組彼此可形成的二張簡易組合。
- 第一輪可換至多 4 張；第二、三輪各補 2 張並可再換 1 張。
- 效果牌以文獻互證、現地踏查、口述補白、修復紀錄、數位建模與尊重場域為主題。
- 效果牌提供抽牌、循環手牌、取回文化牌或己方列區加成；使用後立即進入墓地，不占用三列出牌區，也不直接摧毀或大量扣除對手資源。

### 循序學習支線

七條支線共 43 題，依難度由文化辨識逐步進入方法與倫理判斷：

1. 空間格局
2. 建築裝飾
3. 祭祀文字
4. 地方記憶
5. 研究方法
6. 數位轉譯
7. 保存倫理

每條支線各解鎖一塊拼圖；完成七條支線後可下載完整背景圖與學習獎狀。題目不是只考名稱記憶，也涵蓋資料來源、文獻與田野互證、口述資料限制、數位模型定位、私人文化資產、訪談同意、不確定性標示、影像授權與成效宣稱界線。

## 難度設計

- 簡單：電腦換牌與選牌容許較多隨機性，較晚使用領主能力，資源管理較寬鬆。
- 普通：綜合立即分數、組合分數與後續組合進度，維持一般玩家可接受的策略壓力。
- 困難：評估下一步延伸、組合完成度、回合急迫性、超額出牌成本與 PASS 時機，並在追分時選擇較有效率的牌。

難度差異建立在決策品質與資源管理，不改變玩家與電腦的抽牌數、卡牌力量或基本規則。

## v2.29 介面與公平性基礎

- 稀有度改稱「文化標記」，並移除其對電腦策略的權重。
- 統一卡牌「啟動條件／效果」格式。
- 改善文化標記、表單、結果頁、手機版及高齡友善可讀性。
- 遊戲結束後提供官方文化資產連結與精簡回饋表單；未設定 Google 表單時，可在本機保存並下載 CSV。

## GitHub Pages 上傳

1. 解壓縮 ZIP。
2. 將解壓縮後的全部檔案與資料夾上傳至 GitHub 儲存庫根目錄。
3. 覆蓋既有檔案並提交變更。
4. 等待 GitHub Pages 重新部署，再按 `Ctrl + F5` 強制重新整理。

不可只上傳 `index.html`，否則注音版、英文版、文化支線、圖片與程式資源不會完整更新。
