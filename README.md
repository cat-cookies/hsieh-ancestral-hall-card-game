# 謝氏宗祠・宗族牌局

這是一款以三輪對戰、手牌管理與文化組合技為核心的文化資產教育卡牌遊戲。內容以屏東謝氏宗祠的空間格局、建築裝飾、祭祀文字、宗族制度與地方生活記憶為基礎。

## 網站結構

本版採雙頁設計：

- `index.html`：首頁、領主與難度設定。
- `battle.html`：換牌與實際對戰畫面。

玩家在首頁選擇領主與難度後，按下「開始牌局」會前往對戰頁，並直接進入起手換牌流程。

## v2.9 主要功能

- 頁首功能已整合，避免相同按鈕在上下兩列重複出現。
- 「遊戲指南」集中提供完整規則、組合技與逐步新手教學。

- 支援文化組合技與觸發動畫。

## 必要檔案

GitHub 儲存庫根目錄必須同時保留：

```text
index.html
battle.html
styles.css
assets/
js/
.nojekyll
```

`js/` 內應包含：

```text
cards.js
catalog.js
game.js
home.js
```

不可只上傳 `index.html`，否則對戰頁、卡牌資料、圖鑑與圖片資源將無法完整載入。

## GitHub Pages 更新方式

1. 將 ZIP 解壓縮。
2. 進入 GitHub 儲存庫首頁。
3. 選擇 `Add file → Upload files`。
4. 將解壓縮後的全部檔案與資料夾拖入上傳區。
5. 覆蓋舊檔並按下 `Commit changes`。
6. 等待 GitHub Pages 重新部署，再按 `Ctrl + F5` 強制重新整理。
