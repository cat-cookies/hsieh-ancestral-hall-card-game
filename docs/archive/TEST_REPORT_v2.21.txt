謝氏宗祠・宗族牌局 v2.21 測試報告

一、靜態檢查
1. 12 個 JavaScript 檔案均通過 node --check。
2. 6 個 HTML 入口頁均無重複 id。
3. HTML 所引用的本地頁面、圖片、CSS 與 JavaScript 檔案均存在。
4. 所有頁面資源版本參數均為 v=2.21。

二、語言與注音
1. 正體中文無注音版：index.html、battle.html。
2. 正體中文注音版：index-zhuyin.html、battle-zhuyin.html。
3. 英文版：index-en.html、battle-en.html，僅載入英文卡牌與英文遊戲程式。
4. 注音版測試可在靜態及動態產生的文化支線內容中建立 ruby／rt 注音標記。
5. 英文版換牌介面、選牌效果與文化支線均維持英文。

三、字級與高齡／兒童友善
1. 小、中、大三個按鈕均可切換並同步 aria-pressed 狀態。
2. 桌面版實測：
   - 小：本文 16px、按鈕 15px、次要說明 14px。
   - 中：本文 18px、按鈕 17px、次要說明 16px。
   - 大：本文 21px、按鈕 19px、次要說明 18px。
3. 主要按鈕最小高度為 44px；手機選牌出牌按鈕最小高度為 48px。
4. 文化支線在大字模式下使用內部捲動，不會以縮小文字換取塞入畫面。

四、卡牌操作
1. 點一下手牌：只選取／取消選取並顯示遊戲效果。
2. 快速點兩下同一張手牌：正式出牌。
3. 「打出選取卡牌」：可替代快速雙擊，適合高齡者、兒童及觸控裝置。
4. 實測選取後，效果區會顯示卡名、類型、力量與遊戲效果；按出牌後手牌數由 10 變為 9。
5. 第一張手牌提示箭頭的絕對位置與第一張卡牌中心誤差為 0px，不再指向第二張牌。
6. 提示框同時依 visualViewport 的可視範圍與偏移重新定位。

五、文化支線
1. 中文與英文均顯示 4 條支線。
2. 每條支線可開啟、作答、顯示答案、上一節、下一節及完成。
3. 中文與英文均完成全流程測試，拼圖依序顯示 1／4、2／4、3／4、4／4。
4. 四條支線完成後，姓名欄位、背景圖下載與獎狀下載功能均可使用。
5. 獨立學習模式明確顯示「開始牌局／Start Card Match」與「繼續完成文化支線／Continue Heritage Paths」。
6. 獨立學習模式關閉時返回對應語言首頁，不會留下空白對戰頁。

六、結束與路徑選擇
1. 對戰頁頂端具「結束遊戲／End Game」。
2. 牌局結果提供「繼續玩牌」「完成文化支線學習」「結束遊戲」三種選擇。
3. 結束遊戲會先顯示確認視窗；取消可返回牌局，確認則返回對應語言首頁。

七、視窗與裝置測試
1. 桌面：1366×768。
2. 手機直向：390×844、360×640。
3. 手機橫向：844×390。
4. 上述尺寸在大字模式下均未產生整頁水平或垂直溢位。
5. 手機選牌效果以固定式可讀面板顯示，不會把手牌推到可視範圍外。
6. 360×640 的短螢幕已保留完整的一列手牌高度。

八、瀏覽器自動化結果
1. 中文首頁、中文對戰頁、英文對戰頁與注音版動態支線均無 JavaScript page error。
2. 中文與英文文化支線可完整完成。
3. 中文與英文選取卡牌及明確出牌按鈕均可完成出牌。
