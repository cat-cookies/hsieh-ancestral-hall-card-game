# v2.21 全面檢修紀錄

1. 正體中文正式分為「無注音」與「注音輔助」兩個獨立頁面，另保留獨立英文版。
2. 修正小、中、大字級按鈕失效問題，並提高全站實際字級、觸控目標與行距。
3. 修正第一張手牌效果提示箭頭錯指第二張牌；提示框改依 visualViewport 與被指向卡牌重新定位。
4. 新增「選取卡牌效果區」與「打出選取卡牌」按鈕；手機不必依賴滑鼠懸停或長按。
5. 文化支線重建為四條可互動、可答題、可累積記憶拼圖的學習流程，補入鳳眼、斗栱、五行石、三元及第、七折水路、壽字磚、五穀豐收等資料重點。
6. 獨立文化學習模式始終顯示「開始牌局」與「繼續完成文化支線」選擇，不再把玩家送回錯誤頁面。
7. 牌局結束後明確提供「繼續玩牌」「完成文化支線學習」「結束遊戲」三種選擇。
8. 新增結束遊戲確認視窗，避免誤觸而遺失目前牌局。
9. 重寫新手教學，納入語言、注音、字級、手機操作、選牌確認、文化支線與結束流程。
10. 口述資料與修復／專題資料分別標示，避免把訪談說法誤寫為已確認史實。
