謝氏宗祠・宗族牌局 v2.26 自我檢驗報告
檢驗日期：2026-08-02

一、修正項目
1. 手牌超出視窗
   - 對戰頁改以實際可視區域分配棋盤與手牌高度。
   - 手牌高度、寬度與手牌停靠區依視窗高度自動縮放。
   - 正體中文、注音版與英文版分別檢查；注音版另保留較高標音空間。

2. 「五穀豐收」名稱
   - 卡牌名稱、文化支線標題與教材文字均使用「五穀豐收」。
   - 已刪除把編輯指令誤寫進教材的句子。
   - 教學內容改為直接說明五穀題材與農業生產、歲時循環、安定及豐收願望的關係。

3. 結束遊戲
   - 頂端「結束遊戲」與結算畫面的「結束遊戲」均可開啟確認視窗。
   - 「取消」可關閉確認視窗並留在牌局。
   - 「確認結束」可回到對應首頁：正體版回正體首頁、注音版回注音首頁、英文版回英文首頁。

4. 句子與教材自我校正
   - 移除後設編輯語句，不把命名要求當成文化資產知識。
   - 對訪談資料保留「訪談整理／仍待查證」等資料界線。
   - 修正不完整或容易誤解的五穀豐收說明。

二、程式與內容檢查
- 全部 JavaScript 檔案通過 node --check 語法檢查。
- 搜尋使用者可見內容，未發現「五穀豐收圖樣」或「不加圖樣」等舊文字。
- 確認中英文遊戲程式均已綁定結束遊戲、取消與確認事件。
- 確認注音版回首頁路徑為 index-zhuyin.html。
